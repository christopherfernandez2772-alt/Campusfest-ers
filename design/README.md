# Carpeta Design – CampusFest

Repositorio para los artefactos de diseño y documentación del proyecto **CampusFest**.

------

## Documentación incluida

### ERS – Especificación de Requisitos de Software
**Archivo:** `ERS CampusFest.pdf`  
Incluye propósito, alcance, requisitos funcionales, no funcionales, restricciones y trazabilidad inicial.

### Bitácora 2 – Documento de Análisis y Diseño
**Archivo:** `Bitacora 2.pdf`  
Incluye arquitectura inicial, casos de uso, wireframes, guía de estilos, navegación, actividades realizadas, inconvenientes y evidencias.
